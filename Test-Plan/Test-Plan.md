# TEST PLAN
## E-Commerce Website – Quality Assurance Testing

**Project:** E-Commerce Website Testing  
**Application:** Automation Exercise  
**Testing Type:** Manual Testing, API Testing and Automation Testing  
**Prepared By:** Chathumini Welengodage  
**Project Type:** Individual QA Portfolio Project

---

### 1. Introduction

The purpose of this project is to evaluate the functionality, reliability and usability of an e-commerce web application through different software testing techniques.

The project focuses on identifying defects, validating application behaviour and ensuring that important website features work as expected.

### 2. Testing Objectives

- Verify that website features work according to their expected behaviour.
- Identify functional defects and unexpected behaviour.
- Validate user interactions and input fields.
- Test API endpoints and response data.
- Automate selected test scenarios.
- Document and report identified defects.

### 3. Scope of Testing

The following application modules will be tested:

| Module | Testing Activities |
|---|---|
| User Authentication | Registration, login and logout |
| Products | Product listing, search and product details |
| Shopping Cart | Add, remove and update products |
| Checkout | Checkout information and order placement |
| API | Request methods, status codes and response validation |

### 4. Testing Types

- Functional Testing
- Manual Testing
- API Testing
- Positive Testing
- Negative Testing
- UI Testing
- Regression Testing
- Automation Testing

### 5. Testing Tools

- **Manual Testing:** Web Browser
- **API Testing:** Postman
- **Automation Testing:** Cypress
- **Database Testing:** SQL
- **Defect Tracking:** GitHub Issues
- **Documentation:** Markdown
- **Version Control:** Git and GitHub

### 6. Test Environment

- Application: Automation Exercise
- Operating System: Windows
- Browser: Google Chrome
- API Testing Tool: Postman
- Automation Framework: Cypress

### 7. Test Approach

Testing will be performed in multiple stages.

1. Explore the application and understand its functionality.
2. Prepare test scenarios and detailed test cases.
3. Execute manual test cases.
4. Record actual results and identify defects.
5. Perform API testing using Postman.
6. Automate selected test cases using Cypress.
7. Prepare the final test execution report.

### 8. Entry Criteria

- Application is accessible.
- Testing environment is available.
- Main application features can be accessed.
- Test scenarios are prepared.

### 9. Exit Criteria

- Planned test cases have been executed.
- Test results have been documented.
- Identified defects have been reported.
- API and automation testing results have been recorded.
- Final testing report has been prepared.

### 10. Expected Deliverables

- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Report
- Bug Reports
- Postman Collection
- Cypress Automation Scripts
- Final QA Report
